# 中文 Karteikarten

Persönliche Lern-App für Chinesisch (vereinfachte Zeichen): tägliche
Wiederholung, Strichfolge, Schreibübung, Suche mit Wörterbuch.
Läuft komplett im Browser; der Lernstand bleibt lokal auf dem Gerät.
